# **Typing tester

This is a Python project I made while learning Python.

**What it does**

Creates a tkinter gui and tests your typing speed and accuracy.

**Features**

* Multiple Sentences.
* Auto jump to type box.
* Text wrapping.

**What I learned**

* The min function.
* Widget focuses.
* Standard wpm conversion.
* Text wrapping.

**How to run**

Download the files and run the Python file.
